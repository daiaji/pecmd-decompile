## 7. U-1 更正段（追加, 主代理裁定入稿; 覆盖 §1–§3 的旧钦定表述）

> 依据: `analysis/r24_u1_exit2_writer.md`（活体取证闭环, 动态 ba-w8+du 行文本三轨互证）。
> 三条裁定已全部并入 `r24_034788_draft.c`（就地修改, 非追加补丁）:

1. **否决"IFEX/FIND 恒返 2"; 真实语义 = 条件分派 + 分支行回执行**:
   - 条件真 → 建裸分支行文本重入 PSB（act1 无前缀）→ 返回 = 分支命令自身返回值
     （ENVI→0 / EXEC→0 / WRITE/FILE→2）→ **handler 返回 0 合法且必要**（031/061 必须保持 0）。
   - 条件假 → act2 即 "ELSE <分支>" 行文本（语料中 "ELSE" 由脚本写在 '!' 之后,
     act2 切分后原样携带）→ 嵌套重入 `PECMD_ProcessScriptBlock(act2)`（0x1400357E5）
     → 该行执行返 2（PSB 尾 LAB_14004c525 写槽, 内外两次尾写）→ 处理器回传 2。
   - **草稿修正点（关键）**: 假分支 r13b==0 的嵌套执行对象从 act1 改 **act2**。
     反汇编依据: 0x1400357EC 先 `MOV RDX,[0x60]`(=act2) 再落入 0x1400357C5 共享调用点,
     RDX 全程未重载; U-1 动态实测嵌套行 = "ELSE ENVI R=missing"（013/016）佐证。
   - **删除 CL_C1_STATUS2_POLICY 强制-2 开关与 cl_cond_is_expr_form 判别器**（不再需要）:
     "2" 由 ELSE 行经 PSB 尾写自然产生; 强制会在真分支案（031/061）造成错误翻转。
2. **FIND $X=Y 为等值比较（非子串）**: 016 "hello world" vs "world" → **假**（走 ELSE）;
   031 "pecmd"=="pecmd" → **真**。草稿不实现比较（在 032dc4/PECMD_EvalLoopCondition 内,
   dc 为 StrCmpNIW/StrCmpNW 等值路径）; 草稿全篇无子串逻辑。截稿未见 msvc 032dc4 子串实现,
   若对拍系统相反登记 032dc4 工单（T10）。
3. **"ELSE 前缀行"组装确认**: 假分支分派段（0x1400357EC–0x1400357E5）经直接反汇编核验
   **无 StrBuf 现场拼接**——嵌套文本 = act2 原缓冲（语料形态 `! ELSE CMD` 中 "ELSE" 属
   用户文本, 保留在 act2 内）; 故"组装"在语料语境下指"分支行经处理器选中并回传",
   非新增前缀字串。语料外写法 `!CMD`（无字面 ELSE）的嵌套行与返回留 T5 活体。
