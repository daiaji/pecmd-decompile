## 已确证事实

1. **基础 WRIT 全形式安全** (含修饰符全族、循环上下文、编码内容) — 原版 PECMD.EXE
   实测 39 变体零崩溃、输出文件内容正常。
2. **+0x660 区域定位** (capstone 核验): FUN_14009f070+0x660 附近 = 修饰符/参数扫描区
   (call 0x14005c7c4 AsciiPrefixICmp 族); SplitTokenTrimWs (0x1400675b8) 函数内调用点
   实为 +0x3eb (dc:99702) 与 +0x49e (dc:99718), 均为 64 位传递 (mov rcx,rax)。
3. **正常路径无截断**: dc:99701 SplitTokenAssignVar (FUN_14007f6e4) 返回序列
   `lea rax,[rbp+0x10]` 为 64 位完整指针 → 截断应发生在某个非常规分支
   (引号扫描器路径 / *v 写变量路径 / 偏移定位路径之一)。
4. **触发脚本未留档**: R26-f 时为对拍试录场景, 崩溃导致语料未入库,
   触发写法仅有 HANDOVER 一句登记, 具体脚本已失传。
